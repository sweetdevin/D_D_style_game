# D_D_style_game
 a personal python project 
 I should rename this as a mud style game, an ode to the many hours of my youth spent online not in chat rooms or hangouts but playing a mud slaying dragons and solving quests.
This was a #100daysofcode project. the goal of this project was to practice and improve my python skills, better userstand OOP, data structures, class hierarcry  and interactions. practice and improve my use of github and branches. push my knowledge and new skills with some kind of saving and some kind of background task, this being a game I decided passive healing would be a great background task. 
I accomplished all of those goals, with greater or less success, this project it has grown well beyond my initial vision. the only goal I feel  I fell short on was github, December was a rough month to be working on a coding project during my limited free time but, I digress. This was a very valuable project for me and taught me many good lessons, reinforced some other lessons, and alot about how larger projects come together. I know I could have built much more of a "game" but for me it was much more able building the library behind the game

playing the demo *calling it a demo because of it's size*

using an IDE like vscode: download all files to an empty folder, using the IDE run the play_game file.

using powershell or another terminnal and the bat file. download all the files to an empty folder. copy and paste the path to that folder into the bat file where it says "paste file path here". at which point you can move the bat file anywhere and run it to run the game.
